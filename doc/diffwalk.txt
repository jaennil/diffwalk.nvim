1. INTRODUCTION                                          *diffwalk-introduction*

diffwalk highlights a change in the file you already work in, using gitsigns,
and gives you a panel that is nothing but navigation: one line per file, one
line per hunk. Your LSP, your jumps and your keymaps keep working, because you
never leave the real buffer.

Two things can be walked: the current branch against the default branch, and
a single commit against its parent.

==============================================================================
2. REQUIREMENTS                                          *diffwalk-requirements*

    - Neovim 0.10 or newer
    - gitsigns.nvim, which draws the in-file highlights
    - git in $PATH

==============================================================================
3. COMMANDS                                                  *diffwalk-commands*

                                                              *:DiffwalkBranch*
:DiffwalkBranch         Hunks between the merge base with the default branch
                        and the working tree. The merge base is used so that
                        commits landed upstream after you branched stay out of
                        the diff.

                                                             *:DiffwalkCommits*
:DiffwalkCommits [n]    List the last [n] commits (default: |diffwalk-config|
                        `commits`). <CR> walks the diff of the commit under
                        the cursor, <BS> comes back to the list.

                                                              *:DiffwalkCommit*
:DiffwalkCommit {rev}   Walk the diff of {rev} against its parent. A root
                        commit is diffed against the empty tree.

                                                               *:DiffwalkFiles*
:DiffwalkFiles          Put the changed files of the branch in the quickfix
                        list and set the diff base.

                                                                 *:DiffwalkOld*
                                                                *diffwalk-old*
:DiffwalkOld            Open the current file as it looks at the diff base, in
                        a split beside it, with both sides in diff mode.

                        Removed lines are virtual lines and virtual text
                        cannot hold the cursor, so this is how a deleted
                        function signature gets read, searched or yanked. The
                        buffer is not a file on disk: treesitter highlights
                        it, but no LSP attaches. |diffwalk-config| `keys.close`
                        closes it and turns diff mode off again.

                                                       *:DiffwalkToggleDeleted*
:DiffwalkToggleDeleted  Show or hide removed lines in the file buffers. They
                        are virtual lines, so they push real code down.

                                                               *:DiffwalkReset*
:DiffwalkReset          Drop the diff base, every highlight it turned on and
                        the viewed marks.

==============================================================================
4. PANEL                                                        *diffwalk-panel*

A file line carries the path and the counts, a hunk line the line number, the
kind of the first change and its text: >

    lua/jaennil/plugins/gitsigns.lua  +25 -0
         9  + on_attach = function(bufnr)
<
Default mappings inside the panel:

    <CR>        open the hunk and move there
    o           open it, keep the cursor in the list
    ]f          next file
    [f          previous file
    x           mark as viewed; on a file line, the whole file
    a           show all hunks, or only the unviewed ones
    <BS>        back to the commit list
    q           close the panel

                                                             *diffwalk-viewed*
A viewed hunk carries a check mark and is dimmed, and a file line counts how
many of its hunks are done: >

    ✓ lua/jaennil/plugins/gitsigns.lua  +25 -0  1/1
    ✓      9  + on_attach = function(bufnr)
      lazy-lock.json  +15 -11  0/2
           2  - "fidget.nvim": { "branch": "main", ...
<
Marking is manual: `x` on a hunk line, or on a file line for all of its hunks.
The marks are keyed by file and line for the session only: |:DiffwalkReset|
drops them, and they stop matching once the hunks move under them.

5. CONFIGURATION                                               *diffwalk-config*

setup() is optional. Defaults: >

    require("diffwalk").setup({
      remote = "origin",
      branches = { "master", "main" },
      fetch = true,

      commits = 100,
      height = 15,
      position = "botright",

      linehl = true,
      deleted = true,
      word_diff = true,
      vertical = true,

      colors = {
        added = "#005f00",
        added_word = "#008700",
        added_sign = "#5fd75f",
        removed = "#5f0000",
        removed_word = "#870000",
        removed_sign = "#ff005f",
      },

      keys = {
        open = "<CR>",
        preview = "o",
        next_file = "]f",
        prev_file = "[f",
        mark = "x",
        filter = "a",
        back = "<BS>",
        close = "q",
      },
    })
<
remote          Remote the default branch is looked up on.

branches        Fallbacks used when the remote has no HEAD symref. Set it up
                once with `git remote set-head origin -a` and this is skipped.

fetch           Fetch the default branch before computing the merge base. Set
                to false to work offline against what you already have.

colors          The defaults are the saturated 256-color diff palette, not the
                theme's DiffAdd and DiffDelete: those sit a couple of shades
                above the background and lose against syntax highlighting.

                They are applied to the gitsigns groups, including the word
                diff ones, which otherwise link to TermCursor (reverse video)
                and show up as bright blocks. Inside a fully deleted line the
                word diff is flattened to the line color, since there it would
                only cover ragged chunks of leading whitespace.

vertical        Whether :DiffwalkOld splits vertically.

keys            Set an entry to false or "" to leave it unmapped.

==============================================================================
7. CAVEATS                                                    *diffwalk-caveats*

<CR> opens the current version of the file on disk. For a branch review that
is exact. For an older commit the line numbers drift as far as the file has
moved since that commit, and a file deleted in the working tree is reported
instead of opened.
